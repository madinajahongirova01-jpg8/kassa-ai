# Kassa AI — дизайн «Дафтари катакӣ»

Новый дизайн всего проекта. Он ЗАМЕНЯЕТ старый дизайн из Stitch (цвета, шрифты, вид компонентов).
Идея: школьная тетрадь в клетку, в которой хозяин магазина записывает деньги — только теперь она умная.

## Файлы
- html/ — исходные макеты (HTML со стилями inline). Теги <x-dc>, <helmet> и script "text/x-dc" — служебные теги редактора, их игнорировать; важны разметка и стили внутри.
- screens/ — скриншоты макетов (в скриншотах шрифты могли замениться на запасные: настоящие шрифты указаны ниже).

| Файл | Страница | Маршрут |
|---|---|---|
| 01-imruz-desktop | Имрӯз (обзор) | /app |
| 02-imruz-mobile | Имрӯз, телефон 390px | /app |
| 03-sabti-nav-desktop | Сабти нав (голос → чек) | /app/new |
| 04-nasiya-desktop | Насия | /app/debts |
| 05-daftar-desktop | Дафтар (все записи) | /app/transactions |
| 06-hisobot-desktop | Ҳисобот | /app/reports |

## Цвета (ручки и маркер)
- Чернила (текст, рамки, тёмная кнопка): #1B2340
- Синяя ручка (главный акцент, кнопка микрофона, «Тасдиқ»): #2D4BD8
- Красная ручка учителя (расход, просрочка, предупреждения): #D6453D
- Зелёный (доход, оплачено): #1E9E6A
- Жёлтый маркер (выделение главного числа, лучшая колонка): #FFE45C
- Вторичный текст: #5B6480, третичный: #8A93AD
- Фон-тетрадь: #F6F8FD + клетка 24px линиями #E1E7F6
- Карточки: #FFFFFF; светло-синяя заливка столбцов: #DCE3FA
- Красная линия полей тетради: #F2A6A0

## Шрифты
- Заголовки и большие числа: Unbounded (700/800)
- Текст и интерфейс: Inter
- Суммы, чек, время: JetBrains Mono
- Рукописные заметки на полях: Caveat (только короткие пометки, не основной текст)
Важно: проверить, что у каждого шрифта есть таджикские буквы (ҳ ӣ ӯ ғ қ ҷ — набор cyrillic-ext). Если нет — подобрать похожий шрифт с cyrillic-ext и спросить меня.

## Фирменные элементы
- Главное число дня в виде фразы: «Имрӯз шумо… +1 020 сомонӣ фоида кардед.» с жёлтым маркером под числом.
- Карточки: белые, рамка 1.5px #1B2340, радиус 14–18px, жёсткая тень 4px 4px 0 #1B2340 (без размытия).
- Чек: бумажная лента с зубчатым краем, моноширинный шрифт, пунктирные разделители, штамп «ТАСДИҚ ШУД ✓» синим, повёрнут на −13°.
- Насия: карточки-«стикеры» с полоской скотча сверху, лёгкий поворот ±1–2°; просрочка — красная рамка и красная тень; оплачено — зелёный штамп «ПАРДОХТ ШУД».
- Рукописные пометки (Caveat) синей или красной ручкой: «аз дирӯз 18% беҳтар!», «5 рӯз гузашт — занг занед!».
- Навигация: таблетка с вкладками Имрӯз / Дафтар / Насия / Ҳисобот; активная — тёмная. На телефоне — нижняя панель и большая синяя круглая кнопка микрофона по центру.
- Язык простой: «Пул даромад», «Пул рафт», «Ба шумо қарздоранд» вместо «Доход/Расход/Дебиторка».
